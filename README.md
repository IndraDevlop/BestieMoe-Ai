# BestieMoe-Ai

**BestieMoe-Ai** adalah chatbot AI interaktif berbasis Web yang dirancang sebagai teman ngobrol yang cerdas, ceria, dan berwibawa. Menggunakan teknologi **Google Gemini API**, aplikasi ini mampu memberikan respons yang empati dan mengalir secara real-time.

Fitur Utama
*   **Persona Sahabat Bijak**: Respons yang hangat, cerdas, dan memberikan rasa aman bagi pengguna.
*   **Real-time Streaming**: Teks muncul secara mengalir dengan efek mengetik yang halus.
*   **Smart Scroll**: Navigasi chat yang cerdas, memungkinkan pengguna bebas membaca pesan di atas meskipun teks baru sedang berjalan.
*   **Responsive Design**: Antarmuka bersih dan modern menggunakan Tailwind CSS.

Tech Stack
*   **Backend**: Node.js & Express.js
*   **AI Engine**: Gemini 1.5 Flash (Google Generative AI)
*   **Frontend**: JavaScript (Fetch Stream API) & Tailwind CSS

Cara Menjalankan Secara Lokal
1. Clone Repository
   ```bash
   git clone [https://github.com/IndraDevlop/BestieMoe-Ai.git](https://github.com/IndraDevlop/BestieMoe-Ai.git)
   cd BestieMoe-Ai

2. Install Dependensi
   Jalankan perintah ini untuk mengunduh semua library yang dibutuhkan:
   npm install
4. Konfigurasi API Key
   Buat file .env dan tambahkan API Key Gemini Anda:
   GEMINI_API_KEY=your_api_key_here
   PORT=3000
5. Jalankan Server
   node index.js
   
Akses di: http://localhost:3000
